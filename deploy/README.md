# Deployment README — School Tracker

This README explains how to deploy the app to GCP (Cloud Run + Cloud SQL) and how to run a local smoke test. Commands shown are for Windows PowerShell; adapt to WSL/macOS as needed.

## Prerequisites
- gcloud SDK authenticated and set up
- Docker installed (or use `gcloud builds submit`)
- `openssl` available for generating passwords (optional)

## Quick deploy (PowerShell)
1. Open PowerShell and set project / region:

```powershell
gcloud config set project school-tracker-507002
gcloud config set run/region us-central1
```

2. Export a DB password (generate one if needed):

```powershell
# generate a random password (PowerShell)
$pw = [System.Convert]::ToBase64String((New-Object System.Security.Cryptography.RNGCryptoServiceProvider).GetBytes(18))
$env:DB_PASSWORD = $pw
# or set manually
$env:DB_PASSWORD = "YourStrongPasswordHere"
```

3. Run the deploy script (script uses Secret Manager and a dedicated service account):

```powershell
cd (Join-Path $PSScriptRoot "..") # optional, ensure you're in repo root
.\deploy\gcloud-deploy.sh
```

4. Get the public URL for the Cloud Run service:

```powershell
gcloud run services describe school-tracker --region=us-central1 --platform=managed --format="value(status.url)"
```

## Local build & smoke test (before deploying)
- Build the production bundle and run it locally with `serve` or Docker.

```powershell
# Install deps (if needed)
npm ci --legacy-peer-deps
# Build
npm run build
# Serve locally (port 8080)
npm install -g serve
serve -s dist -l 8080
# Or build the container and run with Docker
docker build -t school-tracker:local .
docker run -p 8080:8080 --env PORT=8080 school-tracker:local
# Open http://localhost:8080 in your browser
```

## Verify DB connectivity (after Cloud Run deploy)
- Connect to the Cloud SQL instance via `gcloud sql connect` to inspect tables:

```powershell
gcloud sql connect school-tracker-db --user=webapp --project=school-tracker-507002
```

- Check Cloud Run logs for runtime errors:

```powershell
gcloud logs read --project=school-tracker-507002 --limit=100
# or: view logs in the Cloud Console (Cloud Run -> Service -> Logs)
```

## Security & maintenance checklist
- Use Secret Manager (the deploy script already stores `DATABASE_URL` there).
- Keep the service account permissions minimal (script creates `school-tracker-run-sa`).
- Enable automated backups for Cloud SQL and set a reasonable retention policy.
- Restrict public network access to Cloud SQL; prefer private IP / connector when possible.
- Add monitoring/alerts in Cloud Monitoring for uptime and errors.
